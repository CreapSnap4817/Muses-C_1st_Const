# はやぶさ 7年60億kmの旅

小惑星探査機「はやぶさ」の旅を、3DのVTRと、回して見られるパーツ解説モデルで学ぶページである。VTRは全18章で、音声の読み上げが付く。パーツ解説では、36のパーツのはたらき、しくみ、式と数値を見られる。

個人が学習用に作ったもので、JAXAの公式ページではない。

## 見る

- 公開ページ：https://creapsnap4817.github.io/Muses-C_1st_Const/
- 手元で開く：このリポジトリをZIPで取得して展開し、`index.html` をブラウザで開く。インターネットにつながっていなくても動く。その場合、文字の書体は端末のものに変わる。

## 中身

| 場所 | 内容 |
|---|---|
| `index.html` | 画面と見た目 |
| `js/` | プログラム。`boot.js` が開き方を見て、読みこみ方を切り替える |
| `assets/` | 質感の画像、イトカワの形、星の位置、陰影のデータ |
| `offline/` | ファイルを直接開いたときに使う、1本にまとめたスクリプトと埋め込みの画像。`js/` と `assets/` から作ったもの |
| `licenses/` | 使っているライブラリとデータのライセンス文 |

## 内容について

- 機体は、公開されている写真と資料に合わせて再現した。内部の並べ方など、資料のない部分は推定で作っている。
- 軌道図は、公表されている日付と軌道要素から計算で再現したもので、実際の軌道データではない。
- JAXAが公開している写真を2点、引用として載せている。ミネルバが撮ったはやぶさの太陽電池パドル（2005年11月12日）と、はやぶさが最後に撮った地球（2010年6月13日）である。加工はせず、場面の中に「出典：JAXA　©JAXA」と表示している。写真の権利はJAXAにある。
